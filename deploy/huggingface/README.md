# LooseEnds

A company brain that finds decisions that changed while the work built on them didn't, promises that passed their deadline, and work whose owners went quiet. Built on FalkorDB, using the public Kubernetes Enhancement Proposals.

Source code, graph model and benchmark: see the GitHub repository linked from the project page.

MCP endpoint for agents: `https://<this-space>.hf.space/mcp`
